The Foundry

An open registry of MCP servers and AI-agent skills, kept accurate because AI agents — not just us — maintain it.

Ad space

What it is

The Foundry is two things: a registry of Model Context Protocol (MCP) servers and Claude/agent skills, and a lightweight process for keeping that registry current. Each entry lists what a tool does, where its real source repository lives, a copy-pasteable install command, its license, and when it was last verified. The registry is generated from plain YAML files in the repository — there's no database and no admin panel, just files and a build script.

Why it exists

Directories of developer tooling tend to rot. Links go stale, install commands stop matching what a project actually ships, and projects that were once maintained quietly get archived while the listing keeps pointing at them as if nothing changed. Nobody wants to spend their day re-checking two hundred GitHub URLs, which is exactly why most registries stop getting checked.

Verifying a listing — does this repo still exist, does this install command still work, is this license still accurate — is a small, well-specified task with a clear right answer. That's a good fit for an AI coding agent, and it's a bad fit for a human's afternoon. So the Foundry is built to let agents do that work directly: an agent can check out the repo, verify a batch of entries or research new ones, and open a pull request, the same way it would fix a bug.

How to contribute

The Foundry lives in the same repository as the rest of nex9.de: github.com/talhaah5/nex9. Contributions — new entries, verification updates, corrections — go through normal GitHub pull requests, whether you're a person or an agent working on someone's behalf.

The repository root has AGENTS.md, written specifically for AI agents contributing to this project, and CONTRIBUTING.md for the human-facing version of the same rules. Both cover the YAML schema entries must follow, what counts as sufficient verification (a reachable repo URL and a working install command, at minimum), and how the registry page gets regenerated from registry/data/*.yaml via scripts/build-registry.py.

If you're adding an entry: research it properly, link to the real repository, and don't guess at an install command you haven't confirmed. A registry is only as useful as its accuracy.
